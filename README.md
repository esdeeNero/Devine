# Devine

Локальный AI-помощник для macOS: чаты, локальные модели GGUF/Ollama, вложения, темы, инструменты работы с файлами и кодом, создание документов, управление Safari и встроенным WebKit-браузером.

Версия 2.6. Слева сверху отображается мини-экран управляемого браузера с увеличением и остановкой задачи.

## Требования

macOS Apple Silicon, Xcode Command Line Tools, Homebrew Python 3 (`/opt/homebrew/bin/python3`), llama.cpp (`llama-server`) либо Ollama. Модели устанавливаются отдельно.

## Сборка

```sh
python3 build.py
open build/Devine.app
```

Сборка устанавливает Python-зависимости в ресурсы приложения и подписывает приложение локальной ad-hoc подписью. Для распространения нужна собственная Developer ID подпись и нотариализация.

## Safari

В настройках Safari включите функции веб-разработчика и «Разрешить удалённую автоматизацию». Devine работает в отдельном окне автоматизации.

## Данные и доступ

История и настройки сохраняются локально в `~/Library/Application Support/Local Chat/` для совместимости. Переписки, модели, токены и пользовательские файлы в репозиторий не включены. Режимы доступа настраиваются в приложении; команды терминала выполняются с правами пользователя. Качество работы зависит от модели.
